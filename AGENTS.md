# Règles du projet SpendLens

## Confidentialité & Données Bancaires
- **Zéro information personnelle en public** : Ne jamais inclure de montants explicites, noms de proches, libellés bancaires réels ou informations personnelles issues des relevés dans les descriptions de Pull Request (PR), les messages de commit, la documentation ou les commentaires de code.
- Utiliser systématiquement des formulations génériques et abstraites (ex: « montant > seuil », « salaire en fin de mois », « virement entre proches »).
