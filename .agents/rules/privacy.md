# Confidentialité & Données Personnelles

- **Ne jamais divulguer d'informations personnelles ou montants réels** :
  - Dans les descriptions de Pull Request (PR), titres de PR, messages de commit, ou commentaires publics, ne jamais mentionner de montants spécifiques, noms de personnes, intitulés de comptes bancaires ou données réelles issues des relevés de l'utilisateur.
  - Toujours utiliser des exemples génériques ou abstraits (ex: « montant >= seuil », « revenus récurrents », « virements entre particuliers »).
